# Demo video script (about 2 minutes)

One complete purchase, recorded on the hosted demo. Read the bold lines aloud; the rest is what to show. Every on-screen claim matches the current build: a **24-hour** escrow review window (shortened to 10 minutes in the demo) and a **7-day** dispute decision.

| Time | Show | Say |
| --- | --- | --- |
| 0:00 | Home page, scroll to "Powered by Zcash" | **"Gallery Arcana is a marketplace for digital goods paid in shielded ZEC. This is the hosted demo: the marketplace runs in your browser and payments are simulated, so no real ZEC moves."** |
| 0:12 | Get started, create an alias | **"No email or ID. An alias and a passphrase."** |
| 0:20 | Market, the "sample sellers are automated" label, open an Arcana Fragment | **"Listings show a public preview. The file itself was encrypted in the seller's browser; the server only stores ciphertext."** |
| 0:32 | Send a chat message, show the automated reply | **"Messages are end-to-end encrypted. This seller is a labelled automated sample."** |
| 0:42 | Checkout: amount, single-use address, memo, ZIP-321 URI | **"Checkout issues an exact ZEC amount, a fresh shielded address and a memo for this invoice only."** |
| 0:55 | Order turns *Funded*, escrow countdown visible | **"Payment confirmed. The money is now in escrow, held by the platform. The buyer has 24 hours to check the file; in this demo that's 10 minutes."** |
| 1:08 | Decrypt locally & verify, checksum match | **"My browser opens the key that was sealed to me and checks the file's SHA-256 against the listing."** |
| 1:20 | Accept delivery, signed receipt | **"I accept, the seller is paid, and the platform signs a receipt. It proves this sale happened here; it isn't a legal title."** |
| 1:30 | Terms page, escrow section | **"If I'd done nothing, payment would release automatically when the 24 hours end. If something was wrong, a dispute freezes it and a reviewer decides within 7 days: release, or a full refund."** |
| 1:42 | Privacy page, operator-visibility list | **"To be clear about the trade-off: during escrow the platform controls the funds and sees amounts and order metadata. It can't read the file, the keys or the messages."** |
| 1:52 | Back to home | **"Behind the demo is a real settlement engine with a scripted end-to-end journey for real Zebra and Zallet on local regtest. Public testnet is implemented and is the next thing we verify."** |

Do not say: "anonymous", "untraceable", "guaranteed private", "you own it", or "72 hours".
